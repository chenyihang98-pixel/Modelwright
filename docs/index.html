能做什么

AI 生成的模型拿到手一般不能直接用。模匠把生成前后的事接成了一条线。

1

生成

图片或文字生成 3D，接 Tripo、Meshy、腾讯混元。三视图、四视图的设定图会自动拆开，也可以让一张正面图先画成四视图。

2

花钱之前先检查

提交前能看到这一单大概花多少积分，图片和参数有问题会先提醒。会扣费的请求不会自动重发。

3

本地后处理

减面、LOD、碰撞体、轴心和尺寸，按「资产类型 × 目标平台」的预设一次做完，不花积分。

4

绑骨和动作

云端绑骨；动作设计台里自己调待机、走、跑、跳，或者导入 Mixamo 的动作。试机场和靶场可以直接操控角色看效果。

5

进 Unity

装好插件后一键发送，材质、预制体（带 LOD 和碰撞体）、Animator 都建好，直接放进场景。

6

资产库

版本历史、文件夹、搜索、回收站，导出 GLB / OBJ / STL / PLY。批量任务排队跑，关掉应用也不丢。

上手

三步

  • 装好打开，跟着引导选一个生成服务。还没有密钥就选「演示（离线）」，它给的是内置的示例模型，用来熟悉流程。
  • 在首页拖一张图进去，或者写一句描述。
  • 结果在「资产」页。进「工作台」可以看网格和贴图、做后处理、绑骨、发送到 Unity。

填密钥

服务密钥在哪拿
Tripo（推荐）中国区 / 国际区，两个区账号不通用，各填各的
Meshymeshy.ai，要先订阅 Pro
腾讯混元生 3DTokenHub，先开通 HY-3D 模型再建 Key，地域选广州

密钥只存在你自己电脑上，用 Windows 自带的加密保存。模匠没有服务器，不收集任何数据。

连 Unity

支持 Unity 2022.3、Unity 6 和团结引擎，Built-in / URP / HDRP 都行。

  • 在「引擎」页添加工程，点「安装插件」，之后在资产上点发送就行。
  • 编辑器开着的话会立刻导入：材质、预制体、LOD、碰撞体都建好并放进场景；带动作的角色会配好 Animator，按 Play 就能动。
  • 没装插件也能发送，只是把文件写进 Assets/Modelwright/，剩下的交给 Unity 默认处理。
  • 工程里没有 glTF 导入器时，发送会问要不要装 glTFast（免费，推荐装）。

已知问题

  • 只有 Windows 版，引擎只接了 Unity。
  • 主要在 Unity 6 上测，Unity 2022.3 和团结引擎测得少，遇到问题请提 Issue。
  • 腾讯混元的云端动作文件在 Unity 里蒙皮会撕裂，是文件本身的问题。混元绑好骨的角色，用动作设计台的「补全基础动作（本地）」来加动作。
  • 动作设计台的动作是程序生成的，不是动捕，做原型和试玩够用；想要更自然的就导入 Mixamo。
  • 裙子和头发没有布料模拟，跑起来裙摆可能穿模。
  • 带骨骼的模型不能在本地减面和做 LOD。

每个版本改了什么，看 更新日志。
