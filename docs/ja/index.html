画像 1 枚から 3D モデルを生成、ワンクリックで Unity へ

画像を入れるか一文を書くだけで、そのまま使えるモデルができあがります。ポリゴン削減、LOD、コライダー、リギング、モーションまで 1 つのウィンドウで完結。無料で、生成には自分の API キーを使います。

できること

AI で生成したモデルは、そのままではなかなか使えません。Modelwright は生成の前後に必要な作業をひとつながりにしました。

1

生成

画像またはテキストから 3D を生成。Tripo、Meshy、Tencent Hunyuan に対応しています。三面図・四面図の設定画は自動で分割され、正面の 1 枚から四面図を描かせることもできます。

2

お金を使う前にチェック

送信前におおよその消費クレジットが分かり、画像やパラメーターに問題があれば先に知らせます。課金されるリクエストが勝手に再送されることはありません。

3

ローカル後処理

ポリゴン削減、LOD、コライダー、ピボットとサイズを、「アセットの種類 × ターゲットプラットフォーム」のプリセットでまとめて処理します。クレジットは消費しません。

4

リギングとモーション

リギングはクラウドで。モーションスタジオで待機・歩き・走り・ジャンプを調整したり、Mixamo のモーションを取り込んだりできます。プレイグラウンドと射撃場でキャラクターを操作して確かめられます。

5

Unity へ

プラグインを入れておけばワンクリックで送信。マテリアル、プレハブ（LOD・コライダー付き）、Animator まで作られ、そのままシーンに配置されます。

6

アセットライブラリ

バージョン履歴、フォルダー、検索、ごみ箱。GLB / OBJ / STL / PLY に書き出せます。バッチ処理はキューで実行され、アプリを閉じても消えません。

スクリーンショット

日本語・英語・中国語で表示できます。このページのインストーラーは日本語で起動します。

はじめかた

3 ステップ

  • インストールして起動し、ガイドに沿って生成サービスを選びます。キーがまだなければ「デモ（オフライン）」を選んでください。内蔵のサンプルモデルが返ってくるので、流れをつかむのに使えます。
  • Home ページに画像をドラッグするか、説明を一文書きます。
  • 結果は Assets ページに入ります。Workspace を開くと、メッシュやテクスチャの確認、後処理、リギング、Unity への送信ができます。

API キー

サービスキーの取得先
Tripo（おすすめ）グローバル / 中国。アカウントは別々で、入力欄も分かれています
Meshymeshy.ai。Pro プランの契約が必要です
Tencent Hunyuan 3DTokenHub。HY-3D モデルを有効にしてからキーを作成します（リージョンは広州）

キーは自分の PC にだけ保存され、Windows の機能で暗号化されます。Modelwright はサーバーを持たず、データは一切収集しません。

Unity との接続

Unity 2022.3、Unity 6、Tuanjie に対応。Built-in / URP / HDRP のどれでも使えます。

  • 「エンジン」ページでプロジェクトを追加して「プラグインをインストール」を押せば、あとはアセットの「Unity に送信」を押すだけです。
  • エディターを開いていればすぐにインポートされ、マテリアル、プレハブ、LOD、コライダーが作られてシーンに配置されます。モーション付きのキャラクターは Animator まで設定されるので、Play を押せば動きます。
  • プラグインなしでも送信できます。その場合はファイルが Assets/Modelwright/ に書き込まれ、あとは Unity の標準インポートに任せます。
  • プロジェクトに glTF インポーターがないときは、送信時に glTFast を入れるかどうか聞かれます（無料、おすすめ）。

既知の問題

  • Windows 版のみ。対応エンジンは Unity だけです。
  • テストは主に Unity 6 で行っています。Unity 2022.3 と Tuanjie はあまりテストできていないので、問題があれば Issue で教えてください。
  • Tencent Hunyuan のクラウドモーションは、Unity でスキニングが崩れます（ファイル側の問題です）。Hunyuan でリギングしたキャラクターには、モーションスタジオの「基本モーションを補完（ローカル）」でモーションを付けてください。
  • モーションスタジオのモーションはプロシージャル生成で、モーションキャプチャではありません。プロトタイプや試遊には十分ですが、より自然な動きが欲しいときは Mixamo を取り込んでください。
  • スカートや髪にクロスシミュレーションはありません。走るとスカートが脚を突き抜けることがあります。
  • ボーン付きのモデルは、ローカルでのポリゴン削減と LOD 生成ができません。
